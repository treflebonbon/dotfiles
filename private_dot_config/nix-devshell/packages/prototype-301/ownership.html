この画面はメモリ内の状態モデルです。実際の Chrome・GitHub・OS は操作しません。独立 profile の分離・再起動は別の実機 probe で確認済みです。前面切替は観測されませんでしたが、カーソルへの影響と Dogfood / Dashboard の共存は未確定です。

判断の境界

  • 同じ PR の本文更新だけを待たせます。異なる PR は同時に進めます。
  • 終了要求は対象の所有者世代が一致する場合だけ有効です。古い要求は再起動後のブラウザを閉じません。
  • クライアントの切断を Chrome の終了と同一視しません。再接続で対象を照合します。
  • 背景処理からの画面表示要求は拒否します。モデルの拒否は OS でのフォーカス保持の証明ではありません。
  • 添付の認証が必要になっても、既存の別タブを閉じたり、手動認証の画面を自動起動したりしません。
