専用2欄の省略対象は従来「実装」とだけ記されていた。v16は提案への適用範囲の明示・拡張として記録し、完全に同一の形式条件だったとは主張しない。3列を使う適合提案を5列不足だけでC3 failにしない。保持状態がある提案の表自体は引き続き必須で、文章だけの省略はC3 failと既存の `state-table-missing` に対応付ける。形式未達だけで6項目の内容点を下げず、説明内容・役割分類と区別する。
