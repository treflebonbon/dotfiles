# ROPの可視化方式の比較

ユーザーの「実装内容の流れを、認知負荷を低くして理解したい」「実装理解・レビュー」という用途に対し、railway、フローチャート、スイムレーンを比較した。比較用HTMLは task worktree の `tmp/wireframe-rop-formats.html`、生成ソースと検査結果は `tmp/rop-format-comparison/` に保存した。比較後、ユーザーの「フローチャートでいい」という選択により、スキルの既定表示をフローチャートへ変更した。

## 比較条件

- 既存のEffect・Rust checkoutモデルを再利用した。Effectは13ノード・16接続、Rustは13ノード・15接続で、各方式の全接続を維持した。
- 処理名と成功・失敗・回復の色を共通にした。長い分岐条件は、全方式で同じ分岐一覧へ移した。
- Railwayは既存の横向き配置と、SVG生成後の経路調整を使用した。フローチャートはMermaidの `flowchart TB`、スイムレーンは `swimlane-beta TB` の標準描画を使用した。
- スイムレーンの区切りは実装スコープ。Effectはcheckout外側・flatMap内側・catchTag回復ハンドラー、Rustはcheckout・load_price・or_else回復ハンドラーとした。呼び出し式とハンドラーの所属を示すもので、成功／失敗による区切りとは異なる。
- 同時に小さく並べず、ネイティブなdetails要素で一方式ずつ同じ幅に表示した。閲覧用JavaScriptと外部依存はない。

## 用途に対する見立て

| 方式           | 主に確認すること                     | 負担・限界                                             | 今回の位置づけ                   |
| -------------- | ------------------------------------ | ------------------------------------------------------ | -------------------------------- |
| フローチャート | 次の処理、分岐先、早期終了           | 成功・失敗の配置や回復範囲は固定されない               | 初読の入口                       |
| スイムレーン   | 関数境界、ハンドラーの所属、戻り先   | レーンの意味を理解する必要があり、縦長になりやすい     | ネストや回復範囲のレビュー       |
| Railway        | 失敗時のスキップ、エラー変換、回復先 | 迂回が増えると長い線と横幅の調整が必要                 | ROPの意味を重点的に確認          |
| シーケンス図   | 呼び出し・返却、参加者間のやり取り   | 分岐の組合せが増えると長くなる                         | 通信や並列処理の補足図           |
| 状態遷移図     | 一つの対象の状態変化                 | 関数の実行順序やResult伝播を直接示す用途には補足が必要 | ドメインのライフサイクルの補足図 |

推奨候補は、初読にはフローチャートと分岐一覧、関数・回復の境界が重要なレビューではスイムレーンを使う構成。RailwayはROPの成功・失敗・回復を重点的に読む場合の選択肢とする。この推奨は今回の実装に対する設計上の判断で、人間の理解時間・正答率を測定した結論ではない。採用する表示はフローチャートと分岐一覧。スイムレーンとRailwayは比較記録として残し、スキルへの表示切り替え機能は追加しない。

スイムレーンはフローチャートに責任区分を加えた表現であり、両者は組み合わせられる。Mermaidの新しいスイムレーン構文は、トップレベルのsubgraphをレーンとして扱う。[Mermaid Swimlanes](https://mermaid.js.org/syntax/swimlanes.html)、[Mermaid Flowchart](https://mermaid.js.org/syntax/flowchart.html)。

## 描画・検証結果

Mermaid 11.17.2で生成した。スイムレーンの横向き版は約3,300〜3,800px幅に広がったため、比較ページでは縦向き版を使用した。縦向き版はEffectが約774 × 1,030px、Rustが約708 × 1,039px。フローチャートはEffectが約1,000 × 760px、Rustが約554 × 760pxだった。これらは今回の内容・設定による結果であり、方式一般のサイズ優劣を示すものではない。

6図それぞれを1440px・390pxのビューポートで確認した。ノード数・接続数の一致、線の端点が対応するノードに接続していること、文字同士の重なり、線の無関係な処理箱への侵入、本文の横はみ出しを検査し、いずれも問題を検出しなかった。狭い画面では図と表を横スクロールする。detailsのキーボード開閉、ネットワーク要求0件、閲覧用script要素0件、JavaScriptエラー0件も確認した。

これは表示方式の比較で、スキルのエージェント比較評価を再実行したものではない。過去の固定評価・成果物は変更していない。
