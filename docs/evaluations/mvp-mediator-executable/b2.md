# B2 メモ — display-only negative control

## Deliverable

最小変更は、既存の合計表示へ既存 formatter を適用し、その表示付近にローカルなヘルプツールチップを置くことです。ツールチップの開閉は当該 View 内だけで保持し、送信・他操作・共有状態を変えません。アプリケーションコード、Mediator、reducer、グローバル状態、実行可能な遷移モデルは追加しません。

## 凍結基準

| # | 判定 | 理由 |
| --- | --- | --- |
| 1 | ○ | 既存の React/TanStack Query とプロジェクト規約を維持し、Effect・Atom・MVP 移行を行わない。 |
| 2 | ○ | 表示だけの変更を View 内に留める。操作の許可、取消、進行を変えないため Mediator/reducer/global state/遷移モデルは不要。 |
| 3 | ○ | compound components の複数 Context consumer はそのまま残す。connector の単一化や forwarding component を導入しない。 |
| 4 | ○ | 合計には既存 formatter を再利用し、ツールチップの開閉だけをローカル状態にする。 |
| 5 | ○ | 業務規則と送信ロジックには手を加えず、現在の所有者を維持する。 |
| 6 | ○ | 確認は、既存 formatter による合計表示と、ツールチップが開閉しても送信など他操作に影響しないことに限定する。未実行のアプリテストを成功とは記載しない。 |

## Trace

| phase | 状態 | 内容 |
| --- | --- | --- |
| 表示 | OK | 既存 formatter が合計を表示する。 |
| ツールチップを開く | OK | 当該 View のローカル状態だけが変わり、説明を表示する。 |
| ツールチップを閉じる | OK | ローカル状態を戻し、説明を隠す。 |
| 送信・他操作 | skipped | この変更の対象外であり、ツールチップ操作から状態変更を発生させない。 |

## Unclear

- Issue: 既存 formatter とツールチップ実装の具体的な名前・配置先は未提示。
- Cause: この評価では実装対象のソースが指定されず、変更方針だけが与えられている。
- General Fix Rule: 既存の formatter と既存のローカル tooltip パターンを検索して再利用し、なければ当該 View 内の最小ローカル状態だけを使う。共有状態やフロー制御を追加しない。

## 任意判断

- ツールチップの開閉手段は既存 UI パターンに合わせる。既存実装がなければ、hover/focus で表示できる最小のアクセシブルな方式を選ぶ。
- 表示整形の失敗時の表現は既存 formatter の振る舞いを変えず、その結果を表示する。
