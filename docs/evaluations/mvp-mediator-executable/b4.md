# B — display-only negative control 実行メモ

## 判断

アプリケーションコード、状態モデル、MVP 移行は不要である。既存の合計値 formatter を呼んで表示し、同じ表示コンポーネント内のローカル state でヘルプツールチップの開閉だけを管理する。

## 凍結基準

| # | 結果 | 理由 |
| --- | --- | --- |
| 1 | ○ | 既存の React/TanStack Query とプロジェクトの構成を維持する。Effect、Atom、MVP への移行を追加しない。 |
| 2 | ○ | 合計表示とツールチップは表示コンポーネント内に留める。Mediator、reducer、グローバル state、実行可能な遷移モデルは作らない。 |
| 3 | ○ | compound components による複数の Context consumer をそのまま許容する。単一 connector や転送コンポーネントを要求しない。 |
| 4 | ○ | 新しい整形処理を作らず既存 formatter を再利用する。ツールチップの開閉は局所 state にする。 |
| 5 | ○ | 業務規則と送信処理は変更せず、既存の所有者に残す。 |
| 6 | ○ | 確認対象は、既存 formatter による合計の表示と、ツールチップを開閉しても送信や他操作に影響しないことに限定する。アプリのテストは実行していないため、成功とは報告しない。 |
