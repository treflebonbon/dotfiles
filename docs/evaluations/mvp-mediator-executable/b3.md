# B: display-only negative control メモ

既存の React/TanStack Query と compound components の共有 Context は維持する。既存の formatter で合計を整形し、送信や他の操作に影響しないローカル state のヘルプツールチップを追加する最小変更とする。Effect、Atom、MVP 移行、Mediator、reducer、グローバル state、実行可能な遷移モデルは追加しない。

## 凍結基準

1. ○ 既存の Query／プロジェクト構成を維持し、Effect・Atom・MVP 移行を行わない。
2. ○ 表示専用の変更を局所化し、Mediator・reducer・グローバル state・実行可能な遷移モデルを導入しない。
3. ○ 複数の Context consumer を維持する。単一 connector や転送コンポーネントを要求しない。
4. ○ 合計の表示には既存 formatter を再利用し、ツールチップの開閉はローカル state に置く。
5. ○ 事業規則と送信ロジックには触れず、既存の所有者を維持する。
6. ○ 合計の既存形式での表示と、ツールチップの開閉が他の操作を変えないことを確認項目にする。アプリテストは未実行であり、成功したとは報告しない。

## トレース

- Understanding: OK — 表示のみで操作の許可・取消・進行を変えない変更である。
- Planning: OK — 既存 formatter の再利用と局所 tooltip state に限定する。
- Execution: skipped — 指示によりアプリコードは変更しない。
- Formatting: OK — 合計の整形は既存 formatter に委ねる。
- 検証: skipped — アプリコードおよびテストを実行していない。実装時は既存の表示形式と tooltip の開閉、送信への非干渉を確認する。
