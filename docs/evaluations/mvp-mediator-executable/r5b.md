## 判定

| # | 判定 | 理由 |
| --- | --- | --- |
| 1 | ○ | 既存の React / TanStack Query とプロジェクトの構造を保つ。Effect、Atom、MVP への移行はこの小修正に不要。 |
| 2 | ○ | 金額整形とヘルプの開閉は表示専用で、送信や他の操作に影響しない。Mediator、reducer、グローバル state、実行可能な状態モデルは追加しない。 |
| 3 | ○ | compound components が共有 Context を複数箇所で読む構成を維持する。単一 connector や転送専用コンポーネントは不要。 |
| 4 | ○ | 合計は既存 formatter で整形し、ツールチップの開閉はその View の local state で持つ。 |
| 5 | ○ | 業務判断、送信、mutation、Query の更新は既存の所有者から動かさない。 |
| 6 | ○ | formatter の既知の表示結果と、ツールチップを開閉しても送信・他操作が変わらないことを確認する。未実行のテストは成功と記載しない。 |
